# EuroJackpot Prognose – kostenlose APK

## APK kostenlos bauen
1. Dieses Projekt in ein eigenes GitHub-Repository hochladen.
2. Oben im Repository auf **Actions** gehen.
3. **Build EuroJackpot APK** auswählen.
4. **Run workflow** anklicken.
5. Nach dem Build den Bereich **Artifacts** öffnen und `EuroJackpot-Prognose-APK` herunterladen.
6. ZIP entpacken und `app-debug.apk` auf dem Android-Handy installieren.

Die APK ist kostenlos. Android kann vor der Installation die Freigabe für Apps aus unbekannten Quellen verlangen.
