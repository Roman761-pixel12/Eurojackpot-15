# EuroJackpot Prognose
Android-Studio-Projekt. Enthält eine Compose-App mit Tipp der Woche, 10 Prognose-Reihen und statistischem Score.

## APK bauen
Projekt in Android Studio öffnen, Gradle synchronisieren und Build > Build APK(s) wählen. Die Debug-APK liegt danach unter app/build/outputs/apk/debug/app-debug.apk.

Hinweis: Für echte automatische Wochenupdates muss im nächsten Entwicklungsschritt eine aktuelle Ziehungsdatenquelle angebunden und ein WorkManager-Job eingerichtet werden. Die enthaltenen Gewichte sind ein Prototyp und keine mathematische Gewinnvorhersage.
